# 🏥 AI-Powered Healthcare Platform

This project is designed to assist patients and healthcare professionals by combining **symptom-based disease prediction**, an **AI-powered health chatbot**, and a **deep learning model for CT scan analysis**.  
It provides early detection, severity scoring, and actionable health suggestions with easy-to-understand outputs.  

---

## ✨ Key Features

### 1️⃣ Symptom-Based Disease Prediction
- Accepts user input such as: `fever`, `cough`, `laziness`, `red eyes`, etc.  
- Predicts possible diseases based on symptoms.  
- Provides a **severity scale (1–5)** for each case.

### 2️⃣ AI Health Chatbot (Gemini API)
- Uses **Gemini API** to answer user queries related to health.  
- Suggests **exercises, precautions, diet recommendations, and do’s & don’ts**.  
- Provides conversational support to patients anytime.

### 3️⃣ CT Scan Analysis with Deep Learning
- Trained **LLM model** that accepts CT scan input.  
- Predicts **cancer severity score (1–5)**.  
- Generates a **heatmap** highlighting cancer nodules.  
- Provides AI-driven **suggestions, do’s & don’ts, and follow-up recommendations**.
